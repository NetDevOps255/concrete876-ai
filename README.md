# concrete876-ai
A collection of AI-driven tools for network operations, infrastructure automation, and systems integration

---

## Overview

**concrete876-ai** is a collection of production-grade tools, integrations, and automation frameworks built at the intersection of network engineering and artificial intelligence. The projects here span enterprise network operations, infrastructure-as-code, AI-assisted tooling via the Model Context Protocol (MCP), and home lab automation.

These tools are designed for real-world environments — not toy examples. Expect Cisco Nexus, Palo Alto, VMware, AWS, and Linux-based infrastructure throughout.

---

## Featured Projects

| Repository | Description |
|---|---|
| `mcp-netbox` | FastMCP server for NetBox — DCIM, IPAM, and virtualization via natural language |
| `mcp-opnsense` | MCP integration for OPNsense firewall management and diagnostics |
| `mcp-paloalto` | Palo Alto Networks MCP server with multi-vsys support |
| `mcp-bookstack` | BookStack documentation MCP server for infrastructure knowledge management |
| `mcp-observium` | Observium network monitoring MCP integration |
| `bgp-monitor` | BGP flap detection and alerting via SNMP, InfluxDB, Grafana, and Telegram |
| `paloalto-access-matrix` | Dark-themed web app for visualizing Palo Alto network access policies |
| `netbox-proxmox-sync` | Automated VM sync between Proxmox and NetBox |
